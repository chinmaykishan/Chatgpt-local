🧠 ChatGPT Clone — Local-Only Version

A clean, minimal ChatGPT-style chatbot that runs completely offline using a custom rule-based local brain — no API key, no backend, no billing required.

This project is perfect for beginners, portfolios, and GitHub Pages demos.


---

🚀 Features

🟢 Works 100% offline — no API key or internet required

🧩 Rule-based “AI brain” for smart responses

🧮 Supports math calculations (calc 12/4)

💬 Handles greetings, jokes, small talk

💾 Saves chat history using localStorage

⏳ Optional typing simulation for realistic feel

🎨 Clean, modern dark UI

🔧 Easily upgradeable to real OpenAI API later
